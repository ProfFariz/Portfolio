# Portfolio Website

A responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

## Sections Included

- Hero
- About
- Skills
- Projects
- Experience
- Contact

## Customize

Update the placeholder content in:

- `index.html` for your bio, projects, contact links, and resume
- `styles.css` for colors, spacing, and visual style

## Deploy To GitHub Pages

1. Push this repository to GitHub.
2. Open the repository settings.
3. Go to `Pages`.
4. Set the source to deploy from the `main` branch root.
5. Save and wait for the site to publish.
